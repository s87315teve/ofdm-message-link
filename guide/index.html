單向 OFDM message link

你在 TX window 打一則 message。RX window 從 OFDM waveform 解出這則 message。這一頁說明中間的每一步。

這個範例的限制
  • 這個範例是 demo。它不是 acceptance test。
  • Link 只有一個方向。它沒有 ACK、ARQ 與 TDD。
  • Link 不會重送遺失的 packet。
  • 請不要用這個範例的數字證明 throughput、reliability 或 RF 效能。

上排是 TX chain，右邊是 channel，下排是 RX chain。Simulation 與硬體只有 sample transport 與 channel 不同。請點一個 block，查看它的說明。

請改變 message 大小與 MCS。頁面用這個範例的 encoder 產生的資料計算 burst。

步驟 1：Message 變成 fragments

一個 fragment 最多 968 bytes。每個 fragment 變成一個 PHY frame。TX 把排隊中的 frames 放進同一個 burst，直到 subframe、byte 或 airtime 的上限。

步驟 2：每一層加上 header

這些長條顯示你選擇的 fragment。寬度不是按比例畫的。

步驟 3：Frames 變成一個 burst

這個長條是按比例畫的。一個 OFDM symbol 有 80 samples：IFFT 的 64 個，加上 cyclic prefix 的 16 個。

    比較 TX 選單的 MCS

    這張表假設一個 burst 只帶你選擇的 fragment。Airtime 包含 STF、LTF 與 SIG，不包含前後的 guard。請點一列來選擇那種 MCS。

    一個 OFDM symbol 裡面有什麼？

    64-point FFT 使用 52 個 subcarriers：48 個放 data，4 個放 pilot。DC subcarrier 與兩側是空的。所以 occupied bandwidth 是 52/64 × sample rate。

    Data（48） Pilot（±7、±21） DC（0） Null（guard band）

    步驟 4：Noise 與 link light

    這是示意圖。它在理想的 constellation points 上加 AWGN。它沒有執行 PHY。

    TX 與 RX 是兩個獨立的程式。它們只共用 sample transport。所以 RX 顯示的內容一定來自 waveform。

    Process layout

    兩個程式預設使用 --engine process。Qt window 在 main process。Radio 與 encode/decode 在 child process。GUI 太忙時，程式丟棄 display event。它不會丟棄 samples。

    tx_app

    Main process：Qt window
    • Cards、60 秒 trend、Send / Signal / Hardware / Log tabs
    • Radio panel：選擇 device、antenna、gain
    ⇅ bounded queue：commands 往下，events 往上
    Engine child process
    • IngressListener：在 UDP :52001 接收 bytes
    • TransmitWorker → MessageTransmitter：fragment、aggregation、encode、組成 burst

    rx_app

    Main process：Qt window
    • Cards、link light、Signal / Decode / Hardware / Log tabs
    • Constellation 與 spectrum 以 15 Hz 重畫（--ui-fps）
    ⇅ bounded queue：滿的時候丟棄 display event
    Engine child process
    • ReceiveWorker → MessageReceiver：一個 owner 依序處理 acquisition 與 header（v5 是 SIG）
    • EgressForwarder：把 message 送到 UDP :52002
    ⇅ 每個 burst 是一個獨立的 segment。結果依照 stream 的順序回來。
